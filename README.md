# Terapi Section

A modern, responsive website for Terapi Section, a mental health and therapy institution. The site provides information about services, team, and contact details, with a clean and calming design.

## Features

- **Landing Page:** Welcoming hero section with animated backgrounds and a clear call-to-action.
- **About Page:** Mission, values, and team introduction.
- **Services Page:** Overview of therapy services with visual cards.
- **Contacts Page:** Contact details and a functional contact form.
- **Responsive Design:** Works well on desktop and mobile devices.
- **Modern UI:** Uses SVGs, floating cards, and geometric backgrounds for a professional look.

## Project Structure

```
├── index.html           # Home page
├── sobre.html           # About page
├── servicos.html        # Services page
├── contactos.html       # Contacts page
├── _css/
│   └── styles.css       # Main stylesheet
├── _js/
│   └── tools.js         # JavaScript for menu and interactivity
├── images/              # Project images (AVIF format)
```

## How to Use

1. **Clone or Download** this repository.
2. Open `index.html` in your browser to view the site locally.
3. All pages are static and require no backend.

## Customization

- Replace images in the `images/` folder as needed.
- Edit text content in the HTML files to fit your institution.
- Update styles in `_css/styles.css` for branding.
